# 모바일 청첩장 셀프 제작 앱 — 기초 기획

> 이 문서는 기획 초기 단계에서 논의된 내용을 정리한 문서입니다. 대화를 통해 계속 업데이트됩니다.

## 1. 한 줄 정의

**예비 신랑/신부가 직접, 자유롭게 조합해서 만드는 모바일 청첩장 제작 앱**
(네이티브 앱에서 제작 → 결과물은 웹 링크로 공유)

## 2. 타겟 사용자

- **1차 타겟**: 예비 신랑/신부 직접 제작 (B2C, 커플 단위)
- 웨딩플래너/업체 대행(B2B2C)은 이후 확장 후보로 남겨둠 — MVP 범위 아님

## 3. 차별화 포인트

기존 셀프 제작 서비스(노웨딩, 청첩장홀 등)는 대부분 **완성된 템플릿을 고르고 텍스트/사진만 교체**하는 방식.

이 앱의 차별점은 **"섹션 조합형 에디터"**:
- 미리 만들어진 블록(섹션) 단위 — 인사말, 갤러리, 지도, RSVP, 계좌번호, 방명록 등 — 를
- 사용자가 **자유롭게 추가·삭제·순서 변경·스타일 커스터마이징**할 수 있음
- 완전 자유 캔버스(Canva형)만큼 자유도가 높진 않지만, 그만큼 **모바일에서 만들기 쉽고 결과물 품질이 안정적**
- "템플릿을 고른다"가 아니라 "내 청첩장을 블록으로 조립한다"는 경험이 핵심 셀링포인트

## 4. 제작 플랫폼

- **제작(에디터)**: 네이티브 앱 (iOS/Android)
- **결과물(청첩장 자체)**: 웹 링크로 공유 (하객은 앱 설치 불필요)

## 5. 모바일 청첩장의 일반적인 구성 요소 (업계 공통 레퍼런스)

향후 섹션 설계 시 참고할 수 있도록, 시장에서 통용되는 구성 요소를 정리:

| 구분 | 구성 요소 |
|---|---|
| **필수 정보형** | 인사말, 신랑/신부(+혼주) 정보, 예식 일시, 예식장 위치+지도, 메인 사진 |
| **비주얼형** | 사진 갤러리(그리드/슬라이드), 인트로 영상, BGM, 스크롤 애니메이션·모션 효과 |
| **참여형** | RSVP(참석 여부 응답), 방명록/축하 메시지, 마음 전하기(계좌번호, 카카오페이 등) |
| **편의형** | 오시는 길(대중교통/주차/셔틀), 캘린더 등록, D-day 카운트다운, 공유하기(카카오톡 등) |
| **부가형** | 신랑신부 인터뷰, 혼주 인사말 별도 섹션, 화환 안내, 식사 안내 |

## 6. MVP 범위 (1차 출시 기준)

아래 4가지 묶음을 모두 MVP에 포함하기로 결정 — 참여형/감성형까지 포함된 **풀 스펙 MVP**:

1. **기본 정보** — 인사말, 신랑신부 정보, 갤러리, 예식장 지도
2. **참여 기능 ①** — RSVP, 계좌번호(마음 전하기) — 신랑측/신부측 구분, 카카오페이 등 연동 고려
3. **참여 기능 ②** — 방명록, 캘린더 연동, D-day 카운트다운
4. **감성 기능** — 배경음악(BGM), 애니메이션/모션 효과 (기본형 무료)

> 참고: 범위가 넓은 편이라 실제 개발 시엔 위 4개 묶음을 **출시 우선순위(스프린트 단위)**로 다시 쪼개는 걸 권장 — 예: ①②는 반드시 1차, ③④는 1차 내 목표지만 일정 압박 시 1.1 버전으로 미루는 식.

## 7. 수익 모델 (추후 적용)

- 구독제·고가 프리미엄 템플릿 판매 ❌
- **포인트 결제형 부분 유료화** — 기본 애니메이션/스타일은 무료, 고급 애니메이션/효과 등은 포인트로 구매
- **1차 출시는 결제 시스템 없이 무료 기본형에 집중**, 결제 기능은 이후 업데이트로 추가

## 8. 포지셔닝 요약

기존 셀프 제작 서비스 = "템플릿 선택 + 텍스트 교체"
이 앱 = "섹션을 자유롭게 조합하는 나만의 청첩장" + "합리적인 부분 유료화(포인트제)"
