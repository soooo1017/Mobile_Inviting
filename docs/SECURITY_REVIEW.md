# 보안 점검 결과 (2026-11-15)

> Supabase 보안 경고(advisor)와 정책(RLS) · 제약 · 보관함 설정을 **읽기만** 해서 점검했어요(설정은 바꾸지 않았어요). 친구 테스트를 넘어 공개하기 전에 다시 점검해요.

## 괜찮은 것
- 모든 표(10개)에 **행 단위 보안(RLS)** 이 켜져 있고, 정책은 전부 "본인 것만"(`auth.uid()` = 주인) 이에요. 초대장 · 응답 · 방명록 · 방문 · 문의 · 알림 설정 · 프로필 모두.
- 하객이 하는 일(응답 · 방명록 · 방문 기록 · 초대장 읽기)은 표를 직접 만지지 않고 **함수**(`submit_rsvp` · `post_guestbook` · `record_visit` · `get_public_invitation`)로만 해요. 함수는 공유 중이고 만료 전인 초대장만 받아요.
- 글자 수 · 값 범위 제한이 표에 걸려 있어요(이름 40자 · 방명록 1000자 · 응답 메시지 500자 · 동반 20명 · 문의 첨부 3개 등).
- 보관함: `inquiry-files`는 **비공개**(본인 폴더만 읽기 · 올리기 · 지우기), `invitation-media`는 본인 폴더만 올리기 · 지우기(공개 읽기는 하객 화면용), 파일 크기 · 종류 제한이 있어요. 개수 상한(문의 200 · 미디어 500)도 있어요.
- 비밀 키(`service_role`)는 앱 · 웹 · Vercel 어디에도 쓰지 않아요. 앱 · 웹에 들어가는 키는 공개용(publishable)뿐이에요.
