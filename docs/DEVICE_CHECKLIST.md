# 폰에서 한꺼번에 확인할 것 (실기기 체크리스트)

> 코드는 타입 검사 · 린트 · 아이폰용 빌드 · 웹 화면 확인까지만 하고, **실제 폰에서는 아직 못 본 것들**이에요. 폰으로 볼 수 있을 때 한 번에 체크하고, 이상한 곳은 항목 옆에 적어서 알려주세요. (2026-10-20 기준 · 새로 만들 때마다 이 목록에 추가)

## 0. 실행
```bash
cd ~/Desktop/Wedding_Mobile_Inviting
git pull origin claude/inspiring-mendel-ksvase
cd mobile
npm install
npx expo start -c
```
- [ ] QR 코드로 Expo Go에서 열림 (같은 와이파이, 안 되면 `npx expo start -c --tunnel`)
- [ ] 로그인 → 내 초대장 목록이 보임

## 1. 상단바 · 하단 (모든 화면 공통)
- [ ] 미리보기의 `편집으로` 버튼이 시간 · 배터리 표시 **아래**에 있고 눌림
- [ ] 갤러리 · 참석 응답 편집 화면의 ✕ / 완료가 눌림
- [ ] 사진 위치 조정 화면의 취소 / 적용이 눌림
- [ ] 사진 크게 보기의 ✕가 눌림
- [ ] 관리 화면 5개의 ← 와 오른쪽 위 버튼이 눌림

## 2. 새 초대장 만들기
- [ ] 2단계 행사 일시: 일자를 누르면 바로 한글 달력, 시간을 누르면 바로 시간 휠이 펼쳐짐 (다시 누르면 닫힘)
- [ ] 펼쳐진 달력이 가운데 정렬
- [ ] 4단계 **배경 · 포인트 색**: 조합 5가지 고르기, [⇄ 배경 · 포인트 바꾸기], 직접
- [ ] 직접 → 배경 줄 / 포인트 줄을 눌러 **색 고르기 창**이 뜨고, 색상 영역 · 밝기 바를 **손가락으로 끌어서** 색이 바뀜
- [ ] 색 코드 입력(예: `#9B4D5C`)하면 색상 영역 · 밝기 바가 따라 움직임
- [ ] 진한 배경으로 바꾸면 글씨 색 기본이 **흰색 (기본)**으로 바뀜, 진한 회색을 고르면 "잘 안 보일 수 있어요" 안내
- [ ] 미리보기 카드의 [참석 의사 전달하기] 버튼 색 · 글씨가 잘 보임 (연한 포인트면 검정 글씨)
- [ ] 글꼴을 바꾸면 미리보기 글씨가 바뀜
- [ ] 제작 시작하기 → 빈 에디터가 열리고 고른 색 · 글꼴이 적용됨
- [ ] 내 초대장 목록의 카드 썸네일이 고른 색으로 보임
- [ ] 예전에 만든 초대장(이전 테마)은 색이 그대로

## 3. 에디터 · 순서
- [ ] 초대장을 **꾹 눌러** 순서 편집으로 들어가고, 카드를 꾹 눌러 끌어서 순서가 바뀜 (끌 때 화면이 같이 스크롤되지 않음)
- [ ] 순서 편집에서 카드 탭 → 복제 · 위로 · 아래로 · 삭제, 삭제 후 되돌리기 토스트
- [ ] 연락처 · 이메일 · 계좌 목록을 꾹 눌러 끌어서 순서 바꾸기
- [ ] 갤러리 편집에서 사진을 꾹 눌러 끌어서 순서 바꾸기
- [ ] 블록 편집 화면 맨 아래 빨간 [삭제하기] → 삭제 + 되돌리기 토스트

## 4. 사진
- [ ] 이미지: 앨범에서 사진 고르기, 사진 위치 조정(끌기 · 두 손가락 확대)
- [ ] 갤러리: 여러 장 한 번에 고르기(최대 30장)
- [ ] 갤러리 슬라이드: 한 화면에 한 장, 밀어서 넘김, **오른쪽 절반 탭 = 다음 / 왼쪽 절반 탭 = 이전** (미리보기에서)
- [ ] 슬라이드의 확대 버튼 → 사진 크게 보기

## 5. 장소 · 지도
- [ ] 장소 이름 · 주소 입력, 주소 복사 아이콘 → "주소를 복사했어요"
- [ ] [네이버 지도] → 앱이 있으면 앱, 없으면 모바일 웹 (주소로 검색됨)
- [ ] [카카오맵] → 같은 방식
- [ ] 링크 직접 넣기(네이버 · 카카오 각각) → 넣은 링크로 열림
- [ ] 버튼 아이콘(초록 핀 · 노란 핀)이 잘 보임

## 6. 배경음악
- [ ] ⚙ 전체 설정 › 배경음악 › **내 음악**: mp3 / m4a 파일 고르기
- [ ] 15MB 넘는 파일 → "15MB까지…" 안내, 다른 형식 → "mp3 · m4a 파일만…" 안내
- [ ] 파일 고르면 이름 · 길이 · 크기가 보이고 **미리 듣기** 재생 / 멈춤, 지우기, 다른 파일로 바꾸기
- [ ] 무음 모드(아이폰 옆 스위치)에서도 미리 듣기 소리가 남
- [ ] 미리보기 오른쪽 위 ♪ 버튼으로 재생 / 끄기, 끝나면 처음부터 반복
- [ ] 곡 고르기 탭은 "곡 목록을 준비하고 있어요"

## 7. 대표 사진 · 감사페이지
- [ ] ⚙ › 대표 사진: 초대장에 넣은 사진이 모여 보이고 하나 고르기
- [ ] 감사페이지 탭: 간단하게(기본) — 제목 · 대표 사진 · 문구 · 보내는 사람이 보임, 누르면 편집 시트
- [ ] 행사 종류별 기본 문구가 맞음 (결혼식 · 돌잔치 · 백일 등), 보내는 사람 표기
- [ ] 간단하게 → 자유롭게: 내용이 텍스트 · 이미지로 옮겨짐
- [ ] 자유롭게 → 간단하게: "자유롭게 만든 감사페이지 내용이 지워지고, / 기본 틀로 다시 시작해요." 확인 창
- [ ] "공개 기간 5. 23. ~ 5. 29. (7일)" 표시와 바꾸기

## 8. 입력 · 키보드 · 달력
- [ ] 편집 시트에서 글을 입력할 때 키보드에 가려지지 않고, 빈 곳을 누르면 키보드가 닫힘
- [ ] 일시 블록의 달력에서 **토요일이 다음 줄로 밀리지 않음**
- [ ] 참석 응답 마감일 달력이 한글 · 가운데 정렬
- [ ] 모든 날짜 달력이 한글

## 9. 관리 화면
- [ ] 내 초대장 카드 → [관리] → 허브(숫자 0 · 메뉴 5개)
- [ ] **작성중** 초대장: 참석 응답 / 방명록 / 통계를 열면 "아직 공유 전인 초대장이에요" + [공유하러 가기] ("준비 중" 안내)
- [ ] **공유중** 초대장: 응답 / 방명록 / 통계 화면이 0으로 보임 (진짜 데이터는 서버 연결 후)
- [ ] 초대장에 참석 응답 · 방명록이 없으면 "에디터로 가기" 안내
- [ ] 프로젝트 설정: 이름 바꾸고 나가면 저장됨
- [ ] 프로젝트 설정: 날짜 · 시간 · 장소 바꾸면 에디터 ⚙ 전체 설정에도 같이 바뀜
- [ ] 감사페이지 사용 토글 / 간단 · 자유 / 공개 기간 1~7일 / 기간 날짜 표시
- [ ] 데이터 내려받기 · 초대장 삭제하기 동작
- [ ] 방명록 설정의 "어느 쪽 손님 받기"(결혼식은 기본 켬)

## 10. My Page · 계정 (예전부터 미뤄둔 것)
- [ ] 닉네임 변경 · 비밀번호 변경 · 회원 탈퇴 · 알림 설정 토글을 끝까지
- [ ] 비밀번호 찾기 메일이 오는지 (안 오면 Supabase 로그 확인)
- [ ] 개인정보처리방침에 "초대장 방문 통계" 문구가 보임

## 11. 안내 팝업
- [ ] 처음에는 에디터 탭이 [초대장] [감사페이지]만 보임 (안내 팝업은 설정에서 쓰기로 해야 탭이 생김)
- [ ] ⚙ 전체 설정 맨 아래 "안내 팝업 사용" 스위치를 켜면 [내용 편집]이 생기고, 에디터에 [안내 팝업] 탭이 생김 (끄면 탭이 사라지고 "사용하지 않더라도 만들어 둔 내용은 보관돼요." 문구)
- [ ] 관리 › 프로젝트 설정의 같은 항목이 ⚙ 전체 설정과 같은 값으로 바뀜, [내용 편집]이 안내 팝업 탭으로 이동
- [ ] 안내 팝업 탭의 팝업 캔버스(330 × 500 고정)가 상단바 · 하단에 가려지지 않고, 작은 폰에서도 화면에 들어감
- [ ] 텍스트 · 이미지 · 구분선 · 여백 · 버튼을 추가하고 편집 (편집 시트가 팝업 아래쪽을 가려도 괜찮은지 — 기존 방식 그대로)
- [ ] 내용이 많으면 팝업 안에서 손가락으로 **스크롤**됨 (아랫줄은 그대로 고정)
- [ ] 아랫줄 ☐ 오늘 하루 보지 않기 · [닫기] 모양 · 색이 초대장 색을 따라가고 잘 보임 (편집 화면에서는 눌리지 않음)
- [ ] 꾹 눌러 순서 편집 · 삭제하기 · 되돌리기가 동작
- [ ] [미리보기]에서 초대장 위에 어둡게 덮고 팝업이 뜸 — [닫기]로 닫힘, 어두운 바깥을 눌러도 닫힘 (체크한 채로 닫아도 같은 규칙)
- [ ] 감사페이지 탭의 미리보기에는 팝업이 안 뜸
- [ ] 안내 팝업을 껐다가 다시 켜면 만들어 둔 내용이 그대로
- [ ] 개인정보처리방침 1항에 "오늘 하루 보지 않기" 임시 저장 문구가 보임
- [ ] (서버 연결 뒤) 게스트 링크에서 오늘 하루 보지 않기 체크 → 같은 날 다시 열어도 안 뜸, 다음 날 다시 뜸
