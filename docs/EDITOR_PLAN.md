# 에디터(B9) 기획안 — 블록 에디터

> 상태: **v7 (2026-10-18) · 와이어프레임 전부 확정, 구현 1~3단계 코드 완료(`mobile/src/editor`, `mobile/src/screens/editor`)**
> 범위: IA 7~8번 — 에디터 메인(B9), 블록 편집, 이미지, BGM, 미리보기. 확정된 결정과 아직 정할 것(§11)을 구분해 적었습니다.

## 1. 핵심 방향 (확정)

- **커스터마이징(블록 조립)이 기본 엔진**이고, **템플릿은 그 블록들을 미리 배치해 둔 시작점(프리셋)**.
- 템플릿을 별도로 개발하지 않음 → 블록 엔진만 잘 만들면 템플릿은 데이터로 계속 추가할 수 있음.
- **엔진과 기능을 먼저 완성하고, 템플릿은 그 엔진을 활용해 나중에 만든다** (템플릿 개수도 그때 결정).
- 같은 엔진을 **감사페이지 자유모드**에서도 그대로 재사용.
- PLANNING.md §3의 셀링포인트("템플릿을 고르는 게 아니라 블록으로 조립한다")는 그대로 유지. 템플릿은 빈 화면에서 시작하는 부담을 덜어주는 출발점 역할.

## 2. 편집 방식 (확정)

- 화면에는 **블록들이 세로로 쌓인 리스트** — **세로 배치만 지원** (좌우로 나란히 놓는 가로 배열은 MVP에서 제외, 필요해지면 나중에 추가)
- 블록을 **탭하면 그 블록 전용 편집 시트/화면**이 열림 (텍스트면 서식+내용, 이미지면 사진 선택 등)
- **꾹 눌러 순서 편집 화면으로**, 블록 추가는 아래 버튼과 순서 편집 화면의 카드 사이 `+`로 (§7)
- 노션처럼 문서 안에서 바로 타이핑하는 인라인 편집은 하지 않음 — React Native에는 웹의 `contentEditable`이 없어 구현 난이도가 매우 높고, 모바일에서는 블록 단위 편집이 더 편함

## 4. 스타일 규칙 (확정)

- **B8 테마 = 배경 · 포인트 색 (2026-10-20 변경)**: 기존 고정 테마 6개(리넨·라벤더·블러시·가든·세이지·잉크)는 없애고 **배경 색 + 포인트 색**을 고름. 글꼴과는 관계없음. 와이어프레임: https://claude.ai/artifact/Mrk3Yu3jhj9H4ViK4U3aSy
  - 색 조합 5가지(각각 두 색: 하늘 `#ebf4f5`·`#b5c6e0` / 노랑 `#faf0ca`·`#0d3b66` / 연두 `#f1f7ed`·`#243e36` / 회색 `#e7ecef`·`#274c77` / 베이지 `#f3e9dc`·`#c08552`) + **직접** 1가지, 모두 6가지. 조합에서 **어느 색을 배경으로, 어느 색을 포인트로 쓸지는 사용자가 정함** — [⇄ 배경 · 포인트 바꾸기]로 서로 바꿈(진한 배경 + 연한 포인트도 가능). 직접은 배경 · 포인트를 각각 고름.
  - **포인트 색이 들어가는 곳**: 버튼(채움 · 테두리), D-day 띠(포인트를 옅게), 달력 행사일 동그라미("테마 색" 고른 경우), 구분선의 점 · 하트. 미리보기 카드에 포인트 색 버튼([참석 의사 전달하기])이 있음.
  - 버튼 글씨는 포인트 색이 연하면 검정, 진하면 흰색으로 **자동**(어떤 조합이든 읽히게).
  - 직접 색 고르기는 **앱 안 색상 선택기**(색상 · 채도 영역 + 밝기 바 + 색 코드). 안드로이드에는 폰 기본 색상 선택기가 없고 아이폰 것만 쓰면 모양이 달라져서, 양쪽이 같은 모양으로 만들었고 Expo Go에서도 동작. 추천 색 칸은 두지 않음.
  - 이미 만든 초대장(이전 테마)은 원래 색 그대로 보이고, ⚙에서 새 방식으로 바꿀 수 있음.
- **글씨 색 (2026-10-20 변경)**: 사용자가 고름 — **검정(기본) · 진한 회색 · 포인트 색 · 직접** 4가지. 블록별 색상 변경은 없음(초대장 전체에 하나). 글씨와 배경의 **대비가 3 미만**(WCAG 대비 비율)이면 "배경과 글씨 색이 비슷해서 잘 안 보일 수 있어요." 안내만 보여주고 고르는 건 막지 않음(예: 진한 배경으로 바꾸면 검정 글씨는 안내, "포인트 색"(연한 색)은 잘 보임).
- (이전 규칙) 글씨 색은 배경 테마에 맞춰 자동 — 밝은 배경은 검정, 잉크는 흰색.
- **글꼴 크기는 서식별로 고정** — 사용자가 크기를 직접 조절하지 않음 → 결과물 품질 유지
- **기본 글꼴은 하나** — 에디터 첫 진입 단계에서 사용자가 직접 고르고, 모든 서식에 적용
- 이후 **블록마다 글꼴을 따로 바꿀 수 있음** — 언제든 "기본 글꼴로 되돌리기"

## 6. 에디터 첫 진입 (확정)

- ✅ **변경 (2026-10-18)**: 기본 글꼴은 새 초대장 마지막 단계(B8 **테마 · 글꼴**)에서 테마와 같이 고름 — 위쪽 미리보기 카드에 고른 테마·글꼴이 바로 보임. 에디터는 **빈 페이지로 시작**. 추천 구성(템플릿)으로 시작은 **출시 뒤 업데이트**로 미룸.
- (원래 안) 에디터에 **처음 들어올 때**(블록이 비어 있을 때) 시작 설정 단계:
  1. **빈 페이지로 시작 / 템플릿으로 시작** 선택
  2. **기본 글꼴** 선택 (한글 글꼴 8종 중 하나)
- 템플릿을 고르면 B7에서 입력한 **호스트 이름·일시·장소를 블록에 자동으로 채움**
- 템플릿 = 기본 블록 조합. 예) 결혼식 기본형:
  `[이미지(커버)] [제목1: 신랑 ♥ 신부] [일시] [제목2 + 본문1: 인사말] [갤러리] [전화번호] [계좌번호] [참석 응답] [방명록]`
- **실제 템플릿 콘텐츠는 엔진 완성 후 제작** — 그전까지는 "빈 페이지로 시작"만으로 개발·테스트
- 작성 도중 템플릿 다시 적용은 MVP에서 제외 — 기존 내용 덮어쓰기 위험

## 7. 에디터 메인(B9) 화면 구성

- **상단**: ← 나가기 / 초대장 제목 / [전체 설정 ⚙] (기본 글꼴·BGM)
- **탭**: [초대장] [감사페이지] — 감사페이지를 쓰는 경우에만 탭 노출. 간단모드면 별도 라이트 편집 화면
- **탭 줄 아래 메뉴 줄 (확정)**: **[순서 편집] [미리보기]** 두 개를 나란히 (블록이 없으면 순서 편집은 꺼짐)
- **모양은 앱의 기존 컴포넌트와 통일 (확정)**
  - [초대장] [감사페이지] 탭 → 문의 화면의 [문의하기 / 문의 내역] 세그먼트 탭과 같은 모양
  - [순서 편집] [미리보기] → 내 초대장 목록의 [필터] 버튼과 같은 모양 (알약형, 아이콘 + 글자)
  - 서식·정렬 같은 선택 항목 → 목록 필터 시트의 칩(`SelectChip`)과 같은 모양 (선택하면 보라색으로 채워짐)
- **에디터는 실제 모습 하나로만 편집 (확정)**: 배경 테마·글꼴·사진이 적용된 완성본 모습 그대로. 요약 카드 보기·보기 토글은 없음 (요약 카드는 순서 편집 화면에서만 씀)
- **블록 탭 → 편집 시트가 바로 열림 (확정)**. 편집 시트에는 블록 메뉴(⋯)가 없음. 내용 수정은 에디터에서만 함
- **블록 추가 (확정)**: 에디터에는 블록 사이 `+`가 없음 (블록이 많을 때 복잡해 보여서)
  - 에디터 아래 고정 **[+ 추가하기]** 버튼 → **맨 아래**에 추가
  - 순서 편집 화면의 **카드 사이 `+`** → **그 자리**에 추가
  - 둘 다 같은 **블록 추가 시트**(기본 / 연락·위치 / 기능 카테고리별)를 열고, 시트 제목 아래에 어디에 추가되는지 표시
- **순서 편집 화면 (확정)**: 블록을 **꾹 누르거나 [순서 편집] 버튼** → 모든 블록이 **요약 카드**로 바뀐 화면
  - 카드를 **탭** → 블록 메뉴: 복제 · 위로 이동 · 아래로 이동 · 삭제 (맨 위/맨 아래면 해당 이동은 꺼짐, 복제는 바로 아래에 생김)
  - 카드를 **꾹 눌러 끌기** → 잡은 카드가 떠오르고, 놓일 자리는 점선으로 표시
  - 손을 떼도 이 화면에 그대로 있고, 오른쪽 위 **[완료]**를 눌러야 실제 모습으로 돌아감
- **삭제 (확정)**: 확인 팝업 없이 바로 지우고 **"되돌리기" 토스트**로 몇 초 안에 복구
- **화면 문구에 "블록"을 쓰지 않음 (2026-10-18 확정)**: "블록"은 기획·개발용 용어일 뿐, 사용자는 "사진 넣어야지, 글 넣어야지"로 생각함. 화면에는 `+ 추가하기` · `삭제하기` · `삭제했어요` · `아직 아무것도 없어요`처럼 쓰고, 종류를 말해야 할 땐 텍스트 · 사진 · 일시처럼 그 이름을 그대로 씀
- **블록 편집 시트에서도 삭제 (2026-10-18 실기기 피드백)**: 모든 블록 편집 시트(전체 화면 편집 포함) 맨 아래에 빨간 **[삭제하기]** 버튼. 누르면 시트가 닫히고 블록이 지워지며, 위와 같은 되돌리기 토스트가 뜸. 하위 화면(글꼴 고르기 · 연락처/계좌 추가·수정 · 은행 고르기)에는 안 보임
- **저장 (확정)**: 자동 저장, **목업 단계에서는 폰 안에 저장**(§10 참고)

### 구현 메모 (2026-10-18)

- 저장: 초대장마다 폰 안(AsyncStorage)에 자동 저장 — 바꿀 때마다 0.4초 뒤 저장.
- 글꼴: Pretendard는 앱에 내장, 나머지 8종은 처음 쓰일 때 불러옴(개발 중에는 Expo 개발 서버에서 받아옴). 출시 전 게스트 웹과 함께 웹폰트/원격 내려받기로 정리 필요 — 지금 방식은 출시 빌드에 글꼴이 모두 포함됨.

- 배경음악 · 사진은 아직 폰 안의 파일 주소로만 저장 — 서버 저장 단계에서 Storage로 올려야 다른 기기 · 게스트에게 보임.
- 프로젝트 목록은 아직 목업(앱을 다시 켜면 처음 상태)이라, 새 프로젝트 id를 겹치지 않게 만들어 예전 초대장 내용이 섞이지 않게 함.
- 게스트 쪽 동작 중 참석 응답 보내기 · 방명록 쓰기/수정/삭제 · 캘린더 추가는 게스트 화면(D) + 서버 저장 단계에서 연결 (미리보기에서는 안내 토스트).
