# 에디터(B9) 기획안 — 블록 에디터

> 상태: **v5 (2026-10-16) · 에디터 구조·기본 블록 확정, 연락·위치 블록 와이어프레임 검토 중**
> 범위: IA 7~8번 — 에디터 메인(B9), 블록 편집, 이미지, BGM, 미리보기. 확정된 결정과 아직 정할 것(§11)을 구분해 적었습니다.

## 1. 핵심 방향 (확정)

- **커스터마이징(블록 조립)이 기본 엔진**이고, **템플릿은 그 블록들을 미리 배치해 둔 시작점(프리셋)**.
- 템플릿을 별도로 개발하지 않음 → 블록 엔진만 잘 만들면 템플릿은 데이터로 계속 추가할 수 있음.
- **엔진과 기능을 먼저 완성하고, 템플릿은 그 엔진을 활용해 나중에 만든다** (템플릿 개수도 그때 결정).
- 같은 엔진을 **감사페이지 자유모드**에서도 그대로 재사용.
- PLANNING.md §3의 셀링포인트("템플릿을 고르는 게 아니라 블록으로 조립한다")는 그대로 유지. 템플릿은 빈 화면에서 시작하는 부담을 덜어주는 출발점 역할.

## 2. 편집 방식 (확정)

- 화면에는 **블록들이 세로로 쌓인 리스트** — **세로 배치만 지원** (좌우로 나란히 놓는 가로 배열은 MVP에서 제외, 필요해지면 나중에 추가)
- 블록을 **탭하면 그 블록 전용 편집 시트/화면**이 열림 (텍스트면 서식+내용, 이미지면 사진 선택 등)
- **꾹 눌러 순서 편집 화면으로**, 블록 추가는 아래 버튼과 순서 편집 화면의 카드 사이 `+`로 (§7)
- 노션처럼 문서 안에서 바로 타이핑하는 인라인 편집은 하지 않음 — React Native에는 웹의 `contentEditable`이 없어 구현 난이도가 매우 높고, 모바일에서는 블록 단위 편집이 더 편함

## 4. 스타일 규칙 (확정)

- **B8 테마 = 배경 색상 테마**. 지금 구조 그대로 유지하며, 글꼴과는 관계없음.
- **글씨 색은 사용자가 고르지 않음** — 배경 테마에 맞춰 자동으로 정해짐: 밝은 배경 5종(리넨·라벤더·블러시·가든·세이지)은 검정 계열, 어두운 **잉크** 테마는 흰색 계열. 첫 진입의 색상 선택, 블록별 색상 변경, 색상 팔레트는 모두 없앰.
- **글꼴 크기는 서식별로 고정** — 사용자가 크기를 직접 조절하지 않음 → 결과물 품질 유지
- **기본 글꼴은 하나** — 에디터 첫 진입 단계에서 사용자가 직접 고르고, 모든 서식에 적용
- 이후 **블록마다 글꼴을 따로 바꿀 수 있음** — 언제든 "기본 글꼴로 되돌리기"

| 서식 | 용도 예시 | 크기(가안) |
|---|---|---|
| 제목1 | 표지 이름, 가장 큰 제목 (예: 신랑 ♥ 신부) | 30 |
| 제목2 | 섹션 제목 (예: 초대합니다, 오시는 길) | 22 |
| 제목3 | 소제목 (예: 신랑측, 신부측) | 18 |
| 본문1 | 기본 본문 (인사말 등) | 16 |
| 본문2 | 작은 글씨 (안내, 캡션) | 13.5 |

정확한 크기는 디자인 단계에서 확정.

## 6. 에디터 첫 진입 (확정)

- 에디터에 **처음 들어올 때**(블록이 비어 있을 때) 시작 설정 단계:
  1. **빈 페이지로 시작 / 템플릿으로 시작** 선택
  2. **기본 글꼴** 선택 (한글 글꼴 8종 중 하나)
- 템플릿을 고르면 B7에서 입력한 **호스트 이름·일시·장소를 블록에 자동으로 채움**
- 템플릿 = 기본 블록 조합. 예) 결혼식 기본형:
  `[이미지(커버)] [제목1: 신랑 ♥ 신부] [일시] [제목2 + 본문1: 인사말] [갤러리] [전화번호] [계좌번호] [참석 응답] [방명록]`
- **실제 템플릿 콘텐츠는 엔진 완성 후 제작** — 그전까지는 "빈 페이지로 시작"만으로 개발·테스트
- 작성 도중 템플릿 다시 적용은 MVP에서 제외 — 기존 내용 덮어쓰기 위험

## 7. 에디터 메인(B9) 화면 구성

- **상단**: ← 나가기 / 초대장 제목 / [전체 설정 ⚙] (기본 글꼴·BGM)
- **탭**: [초대장] [감사페이지] — 감사페이지를 쓰는 경우에만 탭 노출. 간단모드면 별도 라이트 편집 화면
- **탭 줄 아래 메뉴 줄 (확정)**: **[순서 편집] [미리보기]** 두 개를 나란히 (블록이 없으면 순서 편집은 꺼짐)
- **모양은 앱의 기존 컴포넌트와 통일 (확정)**
  - [초대장] [감사페이지] 탭 → 문의 화면의 [문의하기 / 문의 내역] 세그먼트 탭과 같은 모양
  - [순서 편집] [미리보기] → 내 초대장 목록의 [필터] 버튼과 같은 모양 (알약형, 아이콘 + 글자)
  - 서식·정렬 같은 선택 항목 → 목록 필터 시트의 칩(`SelectChip`)과 같은 모양 (선택하면 보라색으로 채워짐)
- **에디터는 실제 모습 하나로만 편집 (확정)**: 배경 테마·글꼴·사진이 적용된 완성본 모습 그대로. 요약 카드 보기·보기 토글은 없음 (요약 카드는 순서 편집 화면에서만 씀)
- **블록 탭 → 편집 시트가 바로 열림 (확정)**. 편집 시트에는 블록 메뉴(⋯)가 없음. 내용 수정은 에디터에서만 함
- **블록 추가 (확정)**: 에디터에는 블록 사이 `+`가 없음 (블록이 많을 때 복잡해 보여서)
  - 에디터 아래 고정 **[+ 블록 추가]** 버튼 → **맨 아래**에 추가
  - 순서 편집 화면의 **카드 사이 `+`** → **그 자리**에 추가
  - 둘 다 같은 **블록 추가 시트**(기본 / 연락·위치 / 기능 카테고리별)를 열고, 시트 제목 아래에 어디에 추가되는지 표시
- **순서 편집 화면 (확정)**: 블록을 **꾹 누르거나 [순서 편집] 버튼** → 모든 블록이 **요약 카드**로 바뀐 화면
  - 카드를 **탭** → 블록 메뉴: 복제 · 위로 이동 · 아래로 이동 · 삭제 (맨 위/맨 아래면 해당 이동은 꺼짐, 복제는 바로 아래에 생김)
  - 카드를 **꾹 눌러 끌기** → 잡은 카드가 떠오르고, 놓일 자리는 점선으로 표시
  - 손을 떼도 이 화면에 그대로 있고, 오른쪽 위 **[완료]**를 눌러야 실제 모습으로 돌아감
- **삭제 (확정)**: 확인 팝업 없이 바로 지우고 **"되돌리기" 토스트**로 몇 초 안에 복구
- **저장 (확정)**: 자동 저장, **목업 단계에서는 폰 안에 저장**(§10 참고)

## 8. 데이터 구조 (개발 참고)

```ts
Invitation {
  themeId: string                                                 // B8 배경 색상 테마 (글씨 색도 여기서 결정)
  font: FontId                                                    // 첫 진입에서 고른 기본 글꼴 (한글 8종 중 하나)
  bgm?: { trackId, autoplay }
  pages: { invite: Block[]; thanks: Block[] }                     // 감사페이지 자유모드도 같은 Block[]
}

Block {
  id: string
  type: 'text' | 'image' | 'gallery' | 'divider' | 'spacer' | 'button'
      | 'map' | 'phone' | 'email'
      | 'datetime' | 'rsvp' | 'guestbook' | 'account'    // 'rsvp' = 화면 이름 "참석 응답"
  props: { ... }                                                  // 블록 종류별 내용
  style?: { font?: FontId; align? }                               // 블록별 덮어쓰기 (없으면 기본 글꼴)
}

FontId = 'pretendard' | 'notoSansKr' | 'gowunDodum' | 'nanumMyeongjo' | 'notoSerifKr'
       | 'nanumPen' | 'hiMelody' | 'gaegu' | 'cormorant'          // cormorant는 블록별로만
```

## 9. 기존 기획(PLANNING.md)과 달라지는 점

## 10. 구현 단계

각 단계는 **와이어프레임 → 확인·수정 → 코드** 순서로 진행 (My Page와 동일한 방식).

1. **블록 엔진 기초** — 데이터 구조, 에디터 메인(실제 모습), 순서 편집 화면(요약 카드), 추가·복제·삭제·순서 변경, 텍스트 블록(서식 5종), 기본 글꼴 적용 — 와이어프레임 6차: https://claude.ai/artifact/J4qbGxx8SYjKzvxHt3kFcs
2. **이미지·갤러리·구분선·여백·버튼** — 블록별 와이어프레임: https://claude.ai/artifact/MPtgfuEB7g52XJFix4BiG1 (✅ 확정 2026-10-16)
3. **기능 블록** — 일시(달력 포함), 전화·이메일(같은 와이어프레임 페이지 5~6번, 3차 검토 중), 계좌번호, 참석 응답·방명록(에디터 배치까지; 실제 응답 수집은 게스트 화면(D)·관리 화면(E)과 함께)
4. **첫 진입 설정 화면 + 전체 설정** — 빈 페이지/템플릿 선택, 기본 글꼴, 블록별 글꼴 변경, BGM
5. **미리보기**, 감사페이지(자유모드 재사용 + 간단모드)
6. **템플릿 제작** — 완성된 엔진으로 행사 유형별 템플릿 추가
